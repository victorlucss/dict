Language
Spoken language for transcription. Auto-detect lets Whisper identify it from your voice.
Flow Mode
Automatically press Return after pasting, so dictated messages send themselves.
Code Mode
Tunes formatting for code — preserves symbols, casing, and inline syntax.
Privacy Mode
Never sends transcriptions to cloud LLMs and stops saving history to disk.
Whisper Model
The GGML model used for transcription. Larger models are more accurate but slower and bigger.

How aggressively the LLM rewrites — from light punctuation fixes to full cleanup.

Which LLM service runs the cleanup. Local providers keep data on your machine.

Name of the model to call, as expected by the selected provider.
Endpoint
API URL requests are sent to. Set automatically from the chosen provider.
API Key
Secret key used to authenticate with the cloud provider.
Tone
How the LLM shapes capitalization and punctuation in the final text.
